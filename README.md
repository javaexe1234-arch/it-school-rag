# CodeCraft Academy — сайт IT-школы

Сайт на HTML + CSS + JavaScript и небольшой сервер на Node.js (без npm-зависимостей) с RAG-ассистентом на Gemini.
База знаний ассистента — документы Word (`.docx` / Google Docs) и таблица Excel (`.xlsx` / Google Таблицы),
которые лежат в папке Google Drive (или локально в `knowledge/`).

## Запуск

1. Скопируйте `.env.example` в `.env` и укажите ключ `GEMINI_API_KEY`.
2. Запустите сервер (нужен Node.js 18+):

```bash
npm start
```

3. Откройте http://localhost:5500

Без сервера (открыв `index.html` напрямую) сайт работает, но AI-ассистент — нет.

## База знаний

| Документ | Формат | Что внутри |
|---|---|---|
| Прайс-лист | Word / Google Docs | курсы, цены, рассрочка, скидки, доп. услуги |
| FAQ | Word / Google Docs | запись, оплата, отмена и перенос, гарантии, подготовка |
| График работы и контакты | Word / Google Docs | адрес, телефон, мессенджеры, режим работы, праздники |
| Преподаватели и расписание | Excel / Google Таблицы | листы «Преподаватели», «Расписание», «Инструкция» |

Исходные файлы — в папке `knowledge/` (их же загружают в Google Drive).

**Документы Word.** Заголовки оформляйте стилями «Заголовок 1 / 2 / 3» (в Google Docs — «Заголовок 1/2/3» или
«Название» для заголовка документа): по ним текст делится на разделы. Таблицы, списки и **жирный** текст поддерживаются.

**Таблица преподавателей.** Это единый источник данных об учителях для сайта и ассистента:
- лист «Преподаватели» — одна строка на учителя: ID, имя и должность на RU/UZ/EN, курсы (через `;`), опыт,
  компания, ссылка на фото, описание на RU/UZ/EN. Порядок строк = порядок карточек на сайте;
- лист «Расписание» — одна строка на занятие: ID преподавателя, день, время (`9:00–11:00`), курс, группа, формат;
- сводка «какой курс в какие дни» для ассистента строится автоматически — она всегда совпадает с расписанием;
- ошибки заполнения (неизвестный ID, непонятный день, пустое имя) видны в логе сервера и в `GET /api/health`.

**Цены на сайте.** Цена за месяц, длительность, полная стоимость, цена при оплате сразу и рассрочка в карточках
направлений берутся из таблицы «Курсы и цены» прайс-листа (`lib/prices.js` → `GET /api/prices`).
Курс сопоставляется с направлением сайта по названию (уточнения в скобках не учитываются); курсы без направления
на сайте (например, «Графический дизайн») просто не показываются. В админке цена и длительность — только для чтения.
Сервер проверяет арифметику (полная стоимость = цена × месяцы, оплата сразу = полная − 10%) и пишет расхождения
в предупреждения `GET /api/health`.

### Запись студентов и свободные места

Записи сохраняются в лист **«Записи»** таблицы «Преподаватели и расписание» (лист создаётся при первой записи):
`Дата записи | Студент | Телефон | Email | Курс | Группа | Преподаватель | Дни и время | Код группы | Статус | Источник | Комментарий`.

- **Группа** = преподаватель + курс + колонка «Группа» листа «Расписание» (например, Frontend · вечерняя · Пн/Ср/Пт 18:00–20:00).
  У каждой группы есть код (`t1-2` = 2-я группа преподавателя `t1`).
- **Свободные места** = вместимость − активные записи. Вместимость — 12 (`GROUP_CAPACITY` в `.env`) или значение колонки
  «Мест» в листе «Расписание». Записи со статусом «Отменена» и «Пробное занятие» место не занимают —
  чтобы освободить место, поменяйте статус строки на «Отменена».
- **Форма на сайте** показывает группы выбранного направления со свободными местами и записывает в таблицу
  (`POST /api/enroll`); можно отметить «только пробное занятие».
- **AI-ассистент** ищет свободные группы (`find_free_slots`: курс, день, утро/день/вечер, преподаватель) и записывает
  (`enroll_student`) — только после того, как повторил данные и получил явное «да» от посетителя.
- Защита: проверка имени и телефона, повторная запись того же телефона в ту же группу не дублируется, запись в полную
  группу отклоняется с вариантами других групп, не больше 5 записей за 10 минут с одного IP.
- Имена и телефоны студентов не попадают ни в базу знаний ассистента, ни в API сайта (`GET /api/slots` отдаёт только
  группы и число мест); в кэше сервера хранятся только хэши телефонов.
- Запись в Google Drive: сервисному аккаунту нужна роль **«Редактор»** для таблицы (или папки). Таблица должна быть в
  формате `.xlsx`; сервер добавляет строку, не трогая остальные листы, а если файл правили в ту же секунду — перечитывает его.

### Как быстро изменения доходят до ассистента и сайта

- Перед каждым ответом ассистента сервер проверяет, не изменились ли документы (не чаще раза в 5 секунд),
  и при изменении сначала перестраивает базу знаний, а потом отвечает.
- В фоне документы проверяются каждые `RAG_POLL_SECONDS` секунд (по умолчанию 15); локальная папка — мгновенно.
- Скачиваются только изменённые файлы, эмбеддинги пересчитываются только для изменённых фрагментов.
- Сайт подтягивает учителей при загрузке, при возврате на вкладку и раз в 20 секунд.
- Принудительная проверка: `POST /api/refresh`. Состояние источника: `GET /api/health` → `knowledge`.
- Последние загруженные данные кэшируются в `.cache/knowledge.json`: если Google Drive временно недоступен,
  сервер работает с последней версией.

## Подключение Google Drive

Сервер читает папку Google Drive через **сервисный аккаунт** Google Cloud (доступ только на чтение).

1. **Проект.** Откройте https://console.cloud.google.com/ → в верхней панели выбор проекта → **New Project**
   (например, `codecraft-rag`) → **Create**.
2. **Google Drive API.** Меню ☰ → **APIs & Services → Library** → найдите **Google Drive API** → **Enable**.
   (Docs API и Sheets API не нужны: файлы экспортируются через Drive API.)
3. **Сервисный аккаунт.** **IAM & Admin → Service Accounts → Create service account** → имя `rag-reader` →
   **Create and continue** → роли не назначайте → **Done**.
4. **Ключ.** Откройте созданный аккаунт → вкладка **Keys → Add key → Create new key → JSON → Create**.
   Скачанный файл переименуйте в `google-service-account.json` и положите в корень проекта
   (он уже в `.gitignore`; никому не отправляйте и не публикуйте его).
   Если создание ключа запрещено политикой организации (`iam.disableServiceAccountKeyCreation`),
   это настраивает администратор организации Google Cloud.
5. **Папка в Google Drive.** Создайте папку, например «CodeCraft — база знаний ассистента», и загрузите в неё
   файлы из `knowledge/`. Рекомендуется открыть их как Google Docs / Google Таблицы
   (Файл → «Сохранить как Google Документ / Таблицу») — так их удобно редактировать в браузере.
   Подходят и сами `.docx` / `.xlsx`, загруженные как есть. В папке должна быть одна таблица преподавателей.
6. **Доступ.** В папке нажмите **Поделиться** → добавьте e-mail сервисного аккаунта
   (`rag-reader@<проект>.iam.gserviceaccount.com`, есть в JSON-ключе в поле `client_email`) с ролью **Читатель**.
7. **Готово.** Если в корне проекта есть `google-service-account.json`, сервер сам находит папку, которой поделились
   с сервисным аккаунтом (если папок несколько — ту, где в названии есть «база знаний» / «knowledge»),
   и в течение ~15 секунд переключается на неё. Пока папки нет — работает с локальной `knowledge/`.
   Чтобы указать папку явно, задайте в `.env` её ID (часть адреса `https://drive.google.com/drive/folders/<ID>`):

```
GOOGLE_DRIVE_FOLDER_ID=<ID папки>
```

8. Проверка: http://localhost:5500/api/health — в `knowledge.source.type` должно быть `google-drive`,
   в `knowledge.files` — ваши документы, `lastError` — `null`. Подсказка о проблеме — в `knowledge.source.note`.
Мгновенные push-уведомления Google Drive требуют публичного HTTPS-адреса сервера, поэтому используется опрос:
лёгкий запрос списка файлов раз в 15 секунд и перед каждым ответом ассистента.

## AI-ассистент (RAG)

Кнопка чата в правом нижнем углу сайта. Ассистент отвечает на русском, узбекском и английском — на языке вопроса.

- Документы преобразуются в базу знаний `kb/knowledge-base.json` (`lib/kb.js`, по навыку `google-ai-studio-rag`):
  записи `{ id, title, text }` по 300–1500 символов, таблицы переписаны в строки «Поле: значение».
  Вручную собрать файл: `npm run build:kb`.
- Поиск гибридный: эмбеддинги `gemini-embedding-001` (70%) + BM25 по ключевым словам (30%).
- В модель `gemini-3.5-flash-lite` передаются 5 самых релевантных фрагментов и последние 6 сообщений диалога.
  При временной перегрузке Google (503/429) запрос автоматически повторяется.
- API-ключи хранятся только на сервере и в браузер не передаются. Ограничение: 20 запросов в минуту с одного IP.

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `admin.html` | Сайт и админ-панель |
| `css/style.css` | Стили, светлая/тёмная тема, адаптив |
| `js/data.js` | Данные сайта, localStorage, тема, синхронизация учителей (`RagSync`) |
| `js/i18n.js`, `js/main.js`, `js/admin.js`, `js/chat.js` | Переводы, логика сайта, админки и чата |
| `server.js` | Сервер: статика, `/api/chat`, `/api/teachers`, `/api/health`, `/api/refresh` |
| `lib/sources.js` | Источники: папка `knowledge/` или Google Drive (сервисный аккаунт) |
| `lib/knowledge.js` | Отслеживание изменений, загрузка и конвертация документов |
| `lib/office.js` | Чтение `.docx` (→ Markdown) и `.xlsx` без зависимостей |
| `lib/teachers-sheet.js` | Таблица преподавателей → данные для сайта и раздел базы знаний |
| `lib/kb.js`, `lib/rag.js`, `lib/gemini.js` | Фрагменты базы знаний, гибридный поиск, клиент Gemini |
| `knowledge/` | Документы базы знаний (локальная копия / для загрузки в Google Drive) |
| `archive/` | Прежние Markdown-версии документов |

## Админ-панель

`admin.html`, демо-доступ: **admin / admin123** (смените в разделе «Настройки»).

- редактирование названия, описания, Hero-медиа и контактов, статистики, направлений, новостей;
- учителя показываются только для просмотра — они ведутся в таблице «Преподаватели и расписание»;
- просмотр заявок с сайта, экспорт в CSV, экспорт / импорт всех данных в JSON.

> ⚠️ Админ-панель — клиентская демо-версия: данные хранятся в `localStorage` браузера, а пароль проверяется в браузере.
> Для настоящего сайта нужен сервер с базой данных и серверной авторизацией.
